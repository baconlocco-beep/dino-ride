# Dino Ride

A little tap-and-play toy for a tablet: ride the dinosaur around a prehistoric scene.

- Tap the dinosaur to make it jump with sparkles.
- Tap an empty spot to drop a star; the dinosaur runs to grab it.
- Tap the flying dino, the horned dino or the baby in the egg for their tricks.

Works offline once loaded. No ads, no tracking, nothing collected.
Install on Android: open the site in Chrome, then menu > Add to Home screen > Install.
